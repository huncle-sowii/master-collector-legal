拾物集支持

记录收藏集、物品与每一件藏品。遇到问题时，请先查看下方说明，也可以与我们联系。

同步与资料

  • 在 App 的「设置 → iCloud 与同步」查看状态；待上传为 0 表示本机没有等待上传的改动。
  • 切换 Apple 账号后，收藏库会与原账号隔离。请先确认手机登录了正确的 iCloud 账号。
  • 「设置 → 备份」可导出完整收藏资料；导出的文件由你自行保存。

AI 辅助

  • AI 是可选功能，需要在「设置 → AI 服务」填入你自己的 OpenRouter API Key 并选择模型。
  • 识别和填写建议可在保存前检查、修改；无法确认的内容应由你核对。
  • 如遇模型拒绝、余额不足或超时，请查看页面的错误详情并尝试其他兼容模型。

联系我们

请将 App 版本、设备型号、操作步骤和错误文字发送至 mastercollector@picaa.com。请勿在邮件中发送 API Key。
